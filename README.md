# 封魔の刻 ― 悪魔を目覚めさせるな ―

▶ **遊ぶ：https://ryowatanabe1161-svg.github.io/fuuma-no-toki/**

ブラウザだけで遊べる、1〜5人用の **協力型カードゲーム（オンライン版）** です。
封印師たちは力を合わせ、2〜99の「封印札」を4本の「封印の列」に納めきって、悪魔 👿 の復活を食い止めます。

> オリジナル作品です（タイトル・世界観・文章・見た目はすべて独自のもの）。

## ルール（かんたん）
- 札は 2〜99 の98枚。**のぼりの列（▲）2本**は1から、**くだりの列（▼）2本**は100から始まります。
- のぼりの列には今より大きい数、くだりの列には今より小さい数を置きます。
- **逆流の術**：のぼりの列に「ちょうど10小さい札」、くだりの列に「ちょうど10大きい札」なら逆向きに置けます（封印が力を取り戻す演出あり）。
- 手札は 1人8枚／2人7枚／3〜5人6枚。自分の番に **2枚以上**（山札が尽きたら **1枚以上**）置き、「手番を終える」で手札上限まで補充。
- 手札がなくなった人の番は飛ばされます。全部置ききれば **封印完了**。手番の人が必要な枚数を置けなければ **悪魔復活**（残った札の枚数がスコア。10枚以下は「見事！」）。
- 数字を伝えるのは禁止。列をタップして **合図**（✋この列は触らないで！／⏳ちょっとだけ待って／👍この列いけるかも／🙋ここは任せて）や **リアクション** で気持ちを伝えます。

## 演出
- **復活ゲージ**（0〜100%）：列の余裕（1枚あたり置ける列の数）、どの列にも置けなくなった札の数、手番の人の手札の苦しさ（置ける手の数・最小の跳び幅・必要枚数を出せるか）から算出。
- 段階に応じて、魔法陣の色が紫→赤に、ひび割れ、赤いビネット、心臓の鼓動のような脈動、悪魔の目が光る、不穏なセリフ（「封印がきしむ…」「何かが目覚めようとしている…」「👿 ……もうすぐだ……」）。
- 大きな跳び（20以上）で画面が揺れ、逆流の術で金色の光と「封印が力を取り戻す」。
- 敗北時は封印が砕けて悪魔が現れる全画面演出、勝利時は金色の光の中で悪魔が封じられる演出。
- 効果音は WebAudio で合成（外部ファイルなし）。最初のタップ以降に鳴り、🔊ボタンで消音。
- 「演出をひかえめに」スイッチと `prefers-reduced-motion` で揺れ・脈動を止められます。

## ファイル
- `index.html`（画面とCSS）、`app.js`（通信・画面・演出・効果音）、`logic.js`（ルールと危険度計算。Nodeでも動作）
- `config.js`：STUN/TURNの設定（TURNを追加すると厳しいNAT環境でもつながりやすくなります）
- `vendor/`：PeerJS 1.5.5（MIT）、qrcode-generator（MIT）を同梱

## しくみ
- PeerJS（WebRTC）による P2P。**ホストのブラウザが審判**で、山札と全員の手札を持ちます。各参加者には自分の手札と公開情報（列の数字・全員の手札枚数・山札の枚数・合図）だけが届きます。決着後に残った手札を公開します。
- 切断しても同じ端末または同じ名前で入り直せば元の席に戻れます。ホストは再読み込み後に「部屋を再開」できます。

## テスト用の隠しURLフラグ（ホストのURLのみ有効）
- `?seed=N`：シャッフルを再現可能に
- `?deck=small`：2〜25の24枚だけ（すぐ決着する勝利テスト用）
- `?deck=5,8,94,...`：配る順番を指定（足りない分は残りの札で補う。`&fill=0` で補わない）
- `?turbo`：演出を短く・効果音なし（自動テスト用）
